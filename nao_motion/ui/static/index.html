L'entraînement n'entraîne aucun mouvement. Par défaut, seules les prises acceptées sont utilisées ; la validation est faite par groupes (une prise de bras et ses prises de tête restent ensemble).

Résultats

Événement

Calibration du guardian, robot par robot : les limites utilisées sur le robot réel viennent uniquement d'ici. Rien n'est commandé : un groupe est relâché pour être guidé à la main, ou raidi sur place. Fermer ou annuler laisse chaque articulation dans son état (pas de retour au repos). Même calcul que nao-motion calibrate.

Aucune calibration ouverte. Connecter le robot (onglet Robot), puis ouvrir.
  1. 1. Exploration des amplitudes
    Tenir le groupe. Au démarrage il est relâché (les autres sont raidis sur place) : amener lentement chaque articulation jusqu'à ses butées utiles et parcourir les combinaisons. À l'arrêt, le groupe est raidi sur place.
  2. 2. Pose de repos
    Relâcher, placer le groupe à la main en position de repos, capturer (moyenne de 5 lectures), raidir sur place. Le repos peut être hors de la zone de mouvement (bras posés sur les genoux) : il n'est borné que par les limites d'usine. Vérifier que la pose de départ est accessible sans heurt depuis le repos : ce trajet direct n'est contrôlé que sur les limites d'usine et la vitesse.
  3. 3. Pose de départ
    Même chose pour la position d'où partent les gestes.
  4. 4. Calcul
    Quand tous les groupes sont explorés et toutes les poses capturées : limites = amplitude explorée ∩ limites d'usine, moins la marge ; contraintes couplées = enveloppes des couples.
  5. 5. Enregistrer puis activer
    Le fichier va dans configs/calibration/ et n'est jamais écrasé. Activer le désigne au guardian (le contrôleur reste désarmé).

Couples explorés

Chaque point est une mesure ; le contour est l'enveloppe convexe d'où viennent les contraintes couplées (marge retirée au calcul). Le cadre pointillé : limites d'usine lues sur le robot (ALMotion.getLimits), ou limites de remplacement si elles n'ont pas pu être lues (simulation).

Connexion (aucun mouvement, aucune raideur modifiée)
